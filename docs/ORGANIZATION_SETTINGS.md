## Owner checklist

1. Open the [organization profile settings](https://github.com/organizations/rishehoffice/settings/profile).
2. Update display name, description, URL, and location where shown.
3. Upload the approved square avatar using **Upload new picture**. A PNG version of the concept can be created from the SVG for upload.
4. Save/Update profile.
5. Verify [organization Overview](https://github.com/rishehoffice) in a signed-out browser.
6. Only public repositories belonging to `rishehoffice` can be pinned as organization repositories; projects hosted in `mahamirmh` are linked through our profile instead.

## Publication policy

- Avoid publishing internal project URLs, credentials, customer records, proprietary architecture or security configuration.
- Use [case studies](../case-studies/README.md) that separate public proof, internal product work, and solution blueprints.
- Do not add unverified revenue, traffic, productivity, hiring or conversion claims.
